# EmotiSense

EmotiSense is an AI-powered web app that analyzes facial expressions and conversation context in real time to help a user recognize social cues.

## Installation

Follow these steps to get your project set up and running locally.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/IHYDIAF/social-cue-hackathon
    cd your-project-repo
    ```

2.  **(Recommended) Create and activate a virtual environment:**
    * **On macOS/Linux:**
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```
    * **On Windows:**
        ```bash
        python -m venv venv
        .\venv\Scripts\activate
        ```

3.  **Install the required dependencies:**
    This project uses a `requirements.txt` file to manage its dependencies. Run the following command to install them:
    ```bash
    pip install -r requirements.txt
    ```

## Usage

Here's how to run the application.

**Example:**

To start the web server, run:
